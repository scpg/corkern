Run `corkern status` to check corkern's health.

- `corkern status` — summary: sync, signing and trust, secrets removed, memory index sizes, hooks, projects.
- `corkern status -v` — full diagnostics: every project's wiring, hook scripts, slash commands, Claude Code memory folders not synced into corkern, knowledge graphs per project, IWE.

Run this when something seems off with memory sync, or after setting up on a new machine. Report problems (✗) and warnings (!) to the user with the fix each line suggests.
